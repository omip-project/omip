# OMIP Project Identity

## Official name

**Open Mission Intelligence Platform**

## Short name

**OMIP**

## One-line description

An open-source platform for mission management, telemetry integration,
environmental context modelling, replay, analytics, and intelligent reasoning
across heterogeneous autonomous vehicles.

## Project category

- Autonomous-systems infrastructure
- Mission data platform
- Vehicle-independent telemetry integration
- Simulation and research platform
- Environmental and safety analytics

## Primary audiences

- Autonomous-systems researchers
- Robotics and software-engineering students
- Vehicle and sensor integration developers
- Universities and laboratories
- Developers building mission-analysis tools
- Teams working with UGV, UAV, AUV and USV systems

## Core principles

1. **Vehicle independent** — shared infrastructure with type-specific profiles.
2. **Data first** — preserve raw data while providing normalised contracts.
3. **Reproducible** — missions retain configuration and environment snapshots.
4. **Observable** — integrity, health and lifecycle information are first-class.
5. **Extensible** — research modules can evolve without destabilising the core.
6. **Open** — documentation, examples and interfaces should support adoption.
7. **Safety conscious** — research functions must not be represented as certified control systems.
